# Built-in fonts for check printing (2.0.0, #157)

Check PDFs use only these fonts, embedded in every PDF, so a check prints the same from any installation. They are
open-licensed (SIL Open Font License 1.1, see the LICENSE files) and listed in THIRD-PARTY-NOTICES.txt.

| Key | Font | Metric-compatible with |
|---|---|---|
| SANS | Liberation Sans 2.1.5 | Arial |
| SERIF | Liberation Serif 2.1.5 | Times New Roman |
| MONO | Liberation Mono 2.1.5 | Courier New |
| CARLITO | Carlito | Calibri (Word's default font) |

Regular and bold of each. The files are unmodified copies of the upstream releases.
