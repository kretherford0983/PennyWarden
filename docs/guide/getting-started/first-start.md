A new installation opens the **Initialization Wizard**.

1. Enter the organization's name.
2. Enter the first Administrator's username, email address, first and last name.
3. Choose a password and type it again (see the password rules on [Signing in](sign-in.md)).
4. Choose **Initialize**. You are signed in as the Administrator.
5. Choose your three security questions when asked — they let you reset a forgotten password.

Next, the Administrator:
- creates the other users under [Users](../users/manage-users.md);
- fills in the organization's details and turns on the optional modules you need in
  [System/About](../system-about/optional-modules.md);
- sets up backups ([Backup and restore](../backup-and-restore/backups.md)).

To move an existing installation instead, choose **Restore from a backup instead** on the first screen (see
[Restoring a backup](../backup-and-restore/restore.md)).
