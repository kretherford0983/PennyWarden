- **Financial Institution:** banks and credit unions that hold your accounts. A Register User can create one, but only
  a Budget Manager can edit it, inactivate it or remove the mark afterwards.
- **Your organization** is an entity too (badge *Your organization*), for example for cash collected at an event. It is
  changed only in [System/About → General](../system-about/system-about-tabs.md).
- **Names to review** (Budget Managers) lists names that may have been split wrongly at an upgrade: **Edit** or
  **Confirm** them.
