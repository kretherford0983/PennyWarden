1. **Entities → New entity** (or **Edit** on a row).
2. Choose **Individual** (a **first name** is required, the last name is optional) or **Organization** (the
   **organization name** is required; first and last name are its contact person).
3. Optional: address, **mailing address** (untick *same as Address* for a P.O. Box), phone, email, notes, **EIN** for
   organizations, a **display name** (untick *Display name same as Name*) and a **Position in the organization** (used
   as a signer's title).
4. With the Invoices module on: **Tax-exempt customer** and its certificate number — see
   [Tax-exempt customers](../invoices/tax-exempt-customers.md).
5. Choose **Save**.

Phone numbers can be typed any way and show as **(555) 123-4567**; add `x204` for an extension or start with `+` for
another country. If a new entity looks like an existing one, PennyWarden shows the possible matches; you can still
create it.
