- **Year-end statements** prints each donor's statement, or **Print all**.
- **Donor report** shows giving per donor per year.

Budget Managers, Budget Users and Auditors see the donation screens read-only.

## Emailing a statement

With the mail server set up, a donor's statement has **Email statement…** next to **Print statement**. It starts from
the statement email in Donations Setup, and sending issues the statement as printing does.
