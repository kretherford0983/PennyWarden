Each release has a demo backup of a made-up club, *Riverside Band Boosters*. Install PennyWarden, choose **Restore from
a backup instead** on the first screen and pick the demo file. The sign-ins and passphrase are in
[the demo guide](https://github.com/kretherford0983/PennyWarden/blob/main/docs/demo.md). Nothing you change in the demo
is kept. The pictures in this guide come from the same demo organization.
