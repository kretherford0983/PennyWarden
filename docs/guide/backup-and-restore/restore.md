1. **System/About → Backups → Restore** (or **Restore from a backup instead** on a new installation).
2. Choose the file and enter its passphrase, your password and `RESTORE`.
3. **What to restore** lets you restore everything, or only Data, Settings, Reminders or Users.
4. Confirm. Everyone is signed out.

Afterwards the **Restore re-entry reports** list what was entered after the backup was made, so it can be entered again.
