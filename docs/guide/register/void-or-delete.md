**Void**
1. Open the transaction's details and choose **Void…**.
2. Give a reason, type `VOID` and confirm. It can't be undone.

The transaction stays in the register as **VOID** with its allocations and attachments, but no longer counts in the bank
balance or the budgets. You can still add notes and attachments. A transaction in a closed Fiscal Year can't be voided.

**Zero-dollar VOID record** records a check that was never used (spoiled, damaged) as a $0.00 VOID on Budget 0, with a
reason, so the check sequence has no gap.

**Delete transaction…** (Register Admin only) removes a transaction that has **not cleared** — for example one entered
twice — with a reason. Auditors still see it as *Deleted*; its check number becomes free again. A transaction with a
printed check must be voided instead.
