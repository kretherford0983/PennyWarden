- **Envelopes**: the #10 envelope templates. Each is *used for* the features you choose, with a default per feature.
- Templates are deactivated, never deleted.
- Each user's **My envelope printer settings** nudge the print for their printer.
- For #10 double-window envelopes nothing is printed on the envelope: the letter or invoice carries the addresses (see
  [Cover letters](../payments/cover-letters.md) and [The invoice PDF](../invoices/invoice-pdf.md)).
