1. **Events → New fundraiser**.
2. Enter the name and description, choose the **Type** (Fundraiser or Event) and the event date(s).
3. Choose the budgets. They can come from up to two Fiscal Years — so a January event can use this year's budget for
   preparation and next year's for the event. A Draft year is enough. You can save without budgets and add them later.
4. Optional: a **Description filter** — only lines whose description contains this text count.
5. Optional: **Continues from** links it with last year's to form a **series**.
6. **Save**.

**Create next year's…** on the page starts next year's event from this one.
