Two-step verification asks for a 6-digit code from an authenticator app on your phone (Microsoft Authenticator, Google
Authenticator, 1Password, Authy…) after your password.

**Set it up**
1. **My account → Two-step verification → Set up** (on a server you are asked at your first sign-in).
2. Scan the QR code with the app, or type the key shown under it.
3. Enter the code the app shows.
4. **Save the 10 recovery codes** somewhere safe — they are shown only once. Each works once instead of a code.

Already have a PennyWarden entry in your authenticator from before? Open **Use my own key instead** and enter that key,
unless it may have been exposed.

**Lost your phone?** On the code screen choose *Lost your phone? Use a recovery code*, then **My account → Change
authenticator** to set up the new phone. Without a phone and codes, ask an Administrator to reset two-step
verification.
